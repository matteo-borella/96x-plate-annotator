# 96x Plate Annotator

An interactive R Shiny application for annotating 96-well experimental plates with customizable metadata.

## Live Application

*[Open 96x Plate Annotator](https://borellamatteo.shinyapps.io/96x-plate-annotator/)**

## Features

- Interactive 96-well plate visualization.
- Customizable metadata variables.
- Well annotation using multiple experimental labels.
- Export of annotations to Excel format.

## Technologies

- R
- Shiny
- RStudio

## Usage

Access the application through the live link above. No local R installation is required to use the deployed version.
